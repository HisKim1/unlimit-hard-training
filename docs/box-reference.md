# 박스 참고 메모 (SPEC 0.1)

박스 모델: https://www.instagram.com/amac_nine/

이번 구현에서는 인스타그램을 직접 열지 않았다. 사용자가 설명한 박스(검은 매트, 흰 벽, 벽 위쪽 파란 띠)와
사용자가 준 박스 배경 그림(`assets/raw/box_background.png`)을 기준으로 삼았다.
인스타그램 사진은 다운로드·저장·에셋 사용하지 않았다.

## 색상 (배경 그림 720x1280 축소본에서 평균값 샘플)

| 부분 | 대략 색 | 메모 |
|---|---|---|
| 매트 | `#4d4c4f` (조명 받은 부분), 어두운 곳 `#1c1c1f` 근처 | 흰 알갱이 섞인 고무 매트, 큰 정사각 타일 |
| 벽 | `#d4cfc9` | 흰색 도장 벽, 하단에 흰 걸레받이 |
| 벽 상단 띠 | `#4069a7` (화면 표시색) / UI 강조색은 `#1f5fd6`·`#2b6ef2` | 뒷벽과 오른쪽 벽을 한 줄로 두름 |
| 리그 | `#2a2b31` | 검은 벽붙이 리그, 기둥 6개 + 가로 철봉 2줄 |
| 천장 | `#8b888b` | 노출 콘크리트 빔, 흰 배관, 사선 LED 조명 |

## 레이아웃 (논리 좌표 720x1280)

- 뒷벽 바닥선: 왼쪽 y≈660 → 오른쪽 y≈630 (살짝 원근)
- 벽 상단 파란 띠: y≈330~360 (왼쪽), 오른쪽 벽에서 y≈395~410
- 리그 기둥 x: 44, 172, 285, 375, 454, 518 / 위쪽 철봉 y≈395(왼쪽)~455(오른쪽)
- 오른쪽 벽 모서리 x≈550
- 매트(설치 가능) 영역: y 700~1010, `src/config.ts`의 `FLOOR_POLYGON`
- 풀업 리그 슬롯: 벽 리그 앞 바닥 3곳 (`RIG_SLOT_POINTS`)
- 천장 고정점(로프·링): 3곳 (`ROPE_ANCHOR_POINTS`), 천장은 화면 위 HUD 뒤로 이어진다고 보고 로프를 위에서 내림
