## 후속 변경: 기구 1회 사용 후 제거

- 모든 기구가 운동 1세션 완료 후 사라진다. WOD 목표는 그대로 유지하므로 Fran은 바벨 3회·풀업 3회를 각각 새 기구로 수행한다.
- 단위 테스트 34개와 프로덕션 빌드 통과. 브라우저에서 바닥·리그·천장 기구가 1회 사용 후 제거되고 WOD 목표가 유지되는 것을 확인했다.
- 새 규칙으로 실제 드래그·재촉 자동 플레이: Fran 58.3초 / 제한 120초, 기구 6개 배치 후 클리어.
- 아래 최초 배포의 8레벨 기록은 변경 전 3회 사용 규칙으로 측정한 기록이다.
